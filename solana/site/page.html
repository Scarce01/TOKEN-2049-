Qu3ee Solana Guard

qUSD-S is a Token-2022 test asset whose every transfer runs through the Qu3ee Guard program. When the Chainlink DON confirms a threat on Base Sepolia, the Guard moves to CONTAINED and the same transfer fails on chain.

Reproduce

git clone https://github.com/Scarce01/TOKEN-2049-
cd TOKEN-2049-/solana && anchor build && bun install && bun test tests   # 16 tests, local validator
cd .. && bun solana/scripts/demo.ts                                    # before / contain / after on devnet
