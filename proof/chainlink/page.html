Qu3ee Chainlink Proof

Three Qu3ee workflows run on the Chainlink DON. Every report they write reaches Base Sepolia through the KeystoneForwarder, signed by the DON's nodes, and carries the workflow id inside the transaction. Each item below links to the transaction or address where you can check it.

Check it yourself

  1. Open any transaction in the table on Basescan. It was sent by a DON node, not by us, and its target is the KeystoneForwarder.
  2. In the logs, the forwarder's ReportProcessed names our Receiver and ends with result true: the Receiver accepted it.
  3. In the input data (report(address,bytes,bytes,bytes[])), rawReport starts with the workflow metadata: the workflow id, the workflow owner , then the DON signatures in the last argument.
  4. The Receiver accepts only whitelisted workflow names from that owner, set through a two-officer timelock. A report from anyone else is refused.
